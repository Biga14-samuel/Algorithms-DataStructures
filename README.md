# Algorithms-DataStructures

# 🐍 Maîtrise de l'Algorithmique avec Python

Bienvenue sur mon portfolio de développeur ! Ce dépôt regroupe l'ensemble de ma progression en algorithmique. J'y explore les concepts fondamentaux, les structures de données complexes et l'optimisation de la performance (Big O).

## 🚀 Structure du Repository

Le projet est organisé par niveaux de difficulté pour refléter mon parcours d'apprentissage :

### 📂 01. Fondamentaux & Logique
* `calculatrice_operateurs.py` : Utilisation des 7 opérateurs arithmétiques.
* `comparaisons_logiques.py` : Maîtrise des booléens et des conditions (IF/ELSE).
* `boucles_iteratives.py` : Manipulation des boucles `For` et `While`.

### 📂 02. Structures de Données
* `tableaux_dynamiques.py` : Gestion des listes (Ajout, suppression, parcours).
* `enregistrements_dataclasses.py` : Création de types personnalisés avec les `dataclasses`.
* `gestion_donnees_complexes.py` : Utilisation de tableaux d'enregistrements (ex: gestion d'une flotte de véhicules).

### 📂 03. Fonctions & Architecture
* `fonctions_procedures.py` : Modularité et réutilisation du code.
* `passage_valeur_vs_reference.py` : Étude de la gestion de la mémoire en Python.
* `recursivite_factorielle.py` : Introduction à la pensée récursive.

### 📂 04. Algorithmes de Tri (Sorting)
* `tri_bulles.py` : Le classique (O(n²)).
* `tri_selection.py` : Recherche du minimum.
* `tri_insertion.py` : La méthode du joueur de cartes.
* `tri_rapide_quicksort.py` : Performance et stratégie "Diviser pour régner" (O(n log n)).

### 📂 05. Algorithmes de Recherche
* `recherche_sequentielle.py` : Recherche simple dans une liste non triée.
* `recherche_dichotomique.py` : Efficacité maximale sur liste triée (O(log n)).

## 📊 Analyse de Complexité (Big O Notation)

Dans ce dépôt, je porte une attention particulière à l'efficacité du code. Voici un résumé des complexités abordées :

| Complexité | Nom | Performance | Exemple d'algorithme |
| :--- | :--- | :--- | :--- |
| **O(1)** | Constante | 🚀 Instantané | Accès direct via Dictionnaire |
| **O(log n)** | Logarithmique | ⚡ Très rapide | Recherche Dichotomique |
| **O(n)** | Linéaire | 📈 Proportionnel | Recherche Séquentielle |
| **O(n log n)** | Lin-Log | 📊 Performant | Tri Rapide (Quicksort) |
| **O(n²)** | Quadratique | 🐢 Lent | Tri à bulles |
